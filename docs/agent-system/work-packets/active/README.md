# work-packets/active — Active Work Packets

Place bounded work packet files here while they are in progress.

## Packet naming convention

`YYYYMMDD-[short-description].md`

Example: `20260805-about-page-build.md`

## Required packet contents

Every packet must specify:

- **Objective** — what must exist when done
- **Approved specification** — the exact agreed design/copy/structure
- **Acceptance criteria** — what the verifier will check (numbered list)
- **File lane** — exact files the builder may touch
- **Relevant decisions** — from DECISIONS.md / PROJECT-TRUTH.md
- **Explicit exclusions** — what is out of scope
- **Expected return** — what the builder must deliver back

When a packet is complete and verified, move it to `../closed/`.
