FLAGSHIP — HERA OS

What if AI felt less like a chatbot and more like a place?

HERA is a local-first AI workspace I designed and built. Agents are characters in rooms. Tasks live on boards. Memory is readable. Every action lands in an event ledger with its real cost. The pixel world is not decoration — it is how the system explains itself.
